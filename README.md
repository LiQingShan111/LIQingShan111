## 项目

### 🌿 医言录 | AI 辅助中医临床记录工具

一个面向中医临床记录场景的软件原型，尝试帮助整理病例信息、形成结构化记录，并保留信息来源与人工确认环节。

**关注的问题**

- 如何把自然语言病例内容整理为结构化信息？
- 如何让提取结果能够追溯到原始内容？
- 如何标记不确定或需要确认的信息，而不是把推测直接当成事实？
- 如何让 AI 辅助记录，同时保留医生的判断与确认权？

**项目阶段：** 已有可运行的软件原型。具体能力以当前实际实现为准。
